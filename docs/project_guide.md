# Documentación del Proyecto

## Descripción General
Este proyecto implementa un sistema de pronóstico de ventas usando técnicas de Machine Learning.

## Fases del Proyecto

### Fase 1: Preparación de Datos
- Importar datos desde `data/raw/`
- Limpieza y transformación
- Guardar en `data/processed/`

### Fase 2: Análisis Exploratorio (EDA)
- Análisis descriptivo
- Identificación de patrones y tendencias
- Detección de anomalías

### Fase 3: Modelado
- Selección de algoritmos
- Entrenamiento y validación
- Guardar modelos en `models/`

### Fase 4: Despliegue
- Integración con Streamlit
- Predicciones en tiempo real
- Monitoreo y mejora continua

## Notebooks Recomendados
1. `01_exploratory_analysis.ipynb` - EDA
2. `02_data_preprocessing.ipynb` - Limpieza de datos
3. `03_model_training.ipynb` - Entrenamiento de modelos
4. `04_model_evaluation.ipynb` - Evaluación y validación
